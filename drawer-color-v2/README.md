# Approved Rev29 drawers — reference-style color 3MF set v2

This set contains all 24 approved Rev29 drawers styled to match the Candy-Cane Village reference more closely. The two rows of frame bumps remain Gold.

Every number uses drawer 1 as its size and position standard. Single digits share its height, depth, and center. Two-digit numbers use the same digit scale and are centered as a pair.

Material order is consistent in every file:

1. Champagne Silk PLA — drawer body and front field
2. White Silk PLA — peppermint/candy-cane white, snowflakes, and angels
3. Candy Red Silk PLA — raised number, hearts, and peppermint/candy-cane red
4. Candy Green Silk PLA — Christmas trees
5. Gold Silk PLA — double-beaded frame, stars, angel halos, and tree toppers

The approved outer dimensions, drawer body, frame, and motifs remain unchanged. Only the raised number shells were normalized. Body facets were subdivided in place to improve the peppermint color pattern without changing the body surface. The STL decorative shells intentionally intersect and remain that way. Import the 3MF directly into the slicer and confirm the five filament mappings before slicing.
