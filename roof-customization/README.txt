Rounded fused snow — first revision

All three STLs retain their original coordinate system and scale. STL units are unspecified.
Snow was added along the front gable edges and roof ridge using smooth scalloped profiles and boolean union. Originals were preserved separately.
Each exported STL was reloaded and verified watertight, with one connected shell and positive volume. Boolean comparison found less than 0.003 cubic model units of numerical difference from the original material.
The left roof had a tiny enclosed boolean cavity (0.0097 cubic model units), which was filled.
These are design-review files; physical fit and slicing have not been tested. Compare the supplied preview before printing.
