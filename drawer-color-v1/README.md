# Approved Rev29 drawers — color 3MF set v1

This set contains all 24 approved Rev29 drawers converted to color 3MF without changing their dimensions or triangle surfaces.

Material order is consistent in every file:

1. Champagne Silk PLA — drawer body and front field
2. White Silk PLA — peppermint/candy-cane white, snowflakes, and angels
3. Candy Red Silk PLA — raised number, hearts, and peppermint/candy-cane red
4. Candy Green Silk PLA — Christmas trees
5. Gold Silk PLA — double-beaded frame, stars, angel halos, and tree toppers

The STL decorative shells intentionally intersect. This topology is preserved so the approved fit and relief are unchanged. Import the 3MF directly into the slicer and confirm the five filament mappings before slicing.
