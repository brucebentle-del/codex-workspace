# Snowy base downloads

The current **v4** base keeps the raised mounting geometry and fuller reference-style holly from v3. Every snowball is 28% larger and lowered to the bottom of the plate; the extreme outside balls move inward so their complete spheres sit on the base. Each internal mound is still divided exactly between adjoining STLs. The three 172 × 184.90 mm sections print independently and align with four recessed underside bow-tie keys.

# Roof customization downloads

The current side roofs are **v24**. The original oversized three-berry cluster remains beneath the window, with a separate compact four-berry holly spray centered on each side. Each shortened inner snow ridge now ends as a continuous smooth rounded roll with no vertical tongue or oval cap. The current center roof is **rev31 v25**. Its recessed bow loops are retained, the two downward ribbon tails are reinforced to close the small printed holes, and the holly is backed into the facade.
